🗄️ SQL data layer · 🐍 Python engine

SQL — standings, computed server-side

SELECT t.team_name,
  COUNT(*) AS played,
  SUM(CASE WHEN ... THEN 1 ELSE 0 END) AS won,
  SUM(goals_for - goals_against) AS gd,
  SUM(points) AS pts
FROM match_results
GROUP BY t.team_name
ORDER BY pts DESC, gd DESC;

Full schema and queries: sql/schema.sql, sql/queries.sql. PostgreSQL-compatible.
