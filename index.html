🗄️ SQL Insights

Standings are SQL aggregations over matches + match_events. Full schema and queries are in sql/.

SELECT t.name, COUNT(m.id) AS played,
 SUM(CASE WHEN winner THEN 3
          WHEN draw THEN 1 ELSE 0 END) AS points
FROM teams t LEFT JOIN matches m ...
GROUP BY t.id
ORDER BY points DESC, diff DESC
